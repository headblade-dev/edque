# edque

Программа виртуальной очереди для тренировки скорости прохождения демо-экзамена.

## Библиотеки

- axum (REST API сервер)
- tokio (асинхронность, только сервер)
- serde и serde_json (сохранение/выгрузка состояния из .json)
- eframe (UI)
- reqwest (HTTP-запросы)

## Возможности

- **Клиент:** "Начать", "Завершить", экран "В работе" с временем, экран результатов, экран блокировки
- **Панель управления:**
  - список компьютеров
  - цветные статусы
  - время начала/завершения
  - поле для ввода баллов (применяется при потере фокуса — клик по пустому месту или Enter)
  - Сброс (сбрасываются баллы и время)
  - Бан (у клиента крупный красный текст ЗАБЛОКИРОВАН, очень эффективно)
  - Вернуть (для тренировки, на случай если студент хочет доделать работу)
  - экспорт отчёта в CSV (галочки для выбора конкретных компьютеров)
- **Эндпоинты сервера:**
  - POST /api/register — регистрация или переподключение клиента
  - GET /api/comps — массив компьютеров и их данных (id, hostname, время начала/завершения, баллы)
  - GET /api/comps/:id — структура (объект) конкретного компьютера
  - POST /api/comps/:id/start, finish, reset, ban, resume, score — управление состоянием
  - POST /api/report — формирование CSV на сервере

## Требования

- Rust (stable) — установка через [rustup](https://rustup.rs/)
- Системные библиотеки для eframe:

**Debian/Ubuntu**

```sudo apt install libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev libssl-dev```

**RHEL/Fedora:**

```sudo dnf install libxcb-devel libxkbcommon-devel openssl-devel```

## Сборка

```cargo build --release```

## Запуск

Бинарники собираются в `target/release/`:

- `edque-server` — сервер (может быть запущен на любой машине, доступной по сети)
- `edque-client` — запускать на компьютерах студентов
- `edque-admin` — панель управления преподавателя

## Хранимые данные

- **Состояние сервера:** `~/.local/share/edque/state.json` (на машине, где запущен сервер)
  Сброс — удалением файла.
- **Отчёты:** `~/.local/share/edque/report-TIMESTAMP.csv` (на машине, где запущен admin)
  Учитывать при полном удалении.
